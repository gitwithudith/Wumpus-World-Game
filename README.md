Follow this Link to play the game: [Wumpus World Game](https://wumpus-world-game-cyan.vercel.app/)

The Wumpus World Game is a logical puzzle in which the player has to safely grab the treasure present in the dark cave and return to the exit point without falling into a pit / without getting captured by the Wumpus monster. 

The player receives hints when they are standing adjacent to the pit / the Wumpus monster / the Gold; If they are standing a block adjacent to the pit, they feel a breeze. If they are standing a block adjacent to the monster, they feel a stench (stink). If they are standing a block adjacent to the gold, the block glitters. 

Scores for each action are as follows: 
 - Escape with gold: +1000
 - Death: −1000
 - Each move: -1
 - Wumpus killed: +10
 - Arrow missed: −10

The cave size for this game is configurable; It can be adjusted to any size between 4x4 to 10x10.
